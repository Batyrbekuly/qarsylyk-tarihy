# Қарсылық шежіресі — 4-топ сайты

Қазақстан тарихы пәніндегі XVIII–XIX ғасырлардағы ұлт-азаттық көтерілістер тақырыбына арналған интерактивті веб-жоба.

## Жобада бар

- Басты бет, интерактивті сызбалық карта және 1783–1869 жылдар хронологиясы
- Сырым Датұлы, Жоламан Тіленшіұлы, Исатай–Махамбет, Кенесары Қасымұлы, Жанқожа Нұрмұхамедұлы және Орал–Торғай қозғалыстары
- 3 ендірілген бейнесабақ
- 10 негізгі тезис, 30 тарихи дерек, 10 тұлға
- Нәтижесі мен түсініктемесі көрсетілетін 5 интерактивті сұрақ
- Дереккөздер бөлімі және мобильді экранға бейімделу

## Іске қосу

Node.js орнатылған компьютерде жоба бумасын ашып, терминалда:

```bash
pnpm install
pnpm dev
```

Терминалда көрсетілген жергілікті мекенжайды браузерден ашыңыз. Жариялауға арналған файлдарды жинау:

```bash
pnpm build
```

## Интернетке жариялау

Бұл жоба Vite арқылы жасалған, сондықтан Vercel немесе Netlify сияқты хостингке GitHub жобасы ретінде жүктеп, build command ретінде `pnpm build`, output directory ретінде `dist` көрсетуге болады. Жарияланғаннан кейін хостинг берген тікелей сілтемені оқытушыға жіберіңіз.

## Ескерту

Карта — өңірлер мен оқиғалардың өзара байланысын көрсетуге арналған сызбалық схема; географиялық дәл навигация картасы емес. Бейне материалдар YouTube желісінен ендіріледі, сондықтан оларды ашу үшін интернет қажет.
